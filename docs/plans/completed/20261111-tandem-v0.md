# tandem v0

## Overview

- Build the first working version of tandem as designed in `README.md`: a Python 3.9+, stdlib-only CLI
  that lets Claude Code (driver by default) and agy (navigator by default) work one task together, both
  in their own visible TUI, talking through a per-session maildir in `~/.tandem/sessions/`.
- Problem it solves: today two agents can't hand work to each other without pasting text into a
  prompt. tandem gives them a shared bus, a content-free doorbell that wakes an idle agent, per-role
  permission profiles that keep the navigator read-only without prompt fatigue, and a log that
  feeds the final summary.
- Integration: nothing is installed globally and nothing is written into the target repo. Each
  launcher (`tandem claude`, `tandem agy`) generates per-session config into the session dir and
  `exec`s the real harness. The user's own Claude and agy config stays untouched.
- Done means: in a real repo, `tandem init`, `tandem claude` in one pane and `tandem agy` in another
  carry a task through plan → review → checkpointed implementation → `tandem done`, with every wake
  happening through the doorbell and no permission prompts for the navigator's normal work.

## Solution Overview

- **One package, one entry point.** `tandem/` is a Python package; `bin/tandem` is a shim that
  resolves its own realpath and imports the package, symlinked into `~/.local/bin` by `make install`.
  Every hook any harness runs is `tandem hook <event>`, so all policy is tested Python, not generated
  shell. Generated configs call the shim by absolute path, so hooks don't depend on the harness's PATH.
- **Maildir per role, no daemon.** `send` allocates an id under an `fcntl.flock`, writes to `tmp/`,
  renames into `new/`, and appends the envelope to `log.jsonl` in the same lock. `recv` renames
  `new/` → `cur/`. Readers never see partial messages; crash recovery is free.
- **Doorbell is a fixed line, rung once per message.** Watchers poll `inbox/<role>/new/` and remember
  the highest id they rang for (`peers/<role>/rung`). A message an agent ignores isn't rung again;
  the next message rings. That avoids wake loops and keeps "a reply is never promised" true.
- **Two watcher modes.** Claude: `tandem watch --once` is the asyncRewake waiter (exit 2 + doorbell on
  stderr; exit 0 just before its deadline; a newer waiter supersedes older ones via pidfile). agy:
  `tandem watch --detach` is started by agy itself through `run_command`, double-forks out of the
  tool call, reads the target conversation id from the session dir on every ring (fixes `/new`),
  and exits when the LS port stops accepting connections (agy restarted or quit) or the session ends.
  `--detach` replaces `nohup … &`, so the start command has no shell metacharacters and matches the
  plain `unsandboxed(tandem)` rule.
- **Bypass forcer is conservative.** The agy `PreToolUse` hook forces `BypassSandbox` only for
  commands that start with a configured test prefix or `tandem` *and* contain no shell
  metacharacters (`; & | < > $ \` ( )` newline). Anything else returns `{"decision":"ask"}` and stays
  sandboxed, so `go test ./... && rm -rf x` can never ride the bypass. For a navigator, a
  write-looking command (agy 1.5.5's sandbox lets the shell write the workspace) gets `force_ask`.
- **Roles live in `session.json`.** Defaults: claude = driver, agy = navigator. A launcher's `--role`
  claims a role; claiming one already held by the other peer is an error.
- **Protocol from one template.** `tandem/templates/protocol.md` (shared rules) plus role and peer
  sections renders to Claude's `--append-system-prompt` and to agy's `.agents/rules/AGENTS.md`.
  Parity by construction.
- **`tandem done` is mechanical.** It writes `summary.md` (task, roles, message timeline, human
  inputs, `decisions.md`), marks the session ended and clears the repo pointer. The narrative
  summary is the driver's job, required by the protocol before it calls `done`.

### Session directory

```
~/.tandem/
  sessions/<repo>--<name>/
    session.json
    lock                       # flock target for id allocation + log append
    inbox/{driver,navigator,human}/{tmp,new,cur}/
    log.jsonl
    plan.md  decisions.md  summary.md  review-N.md
    peers/claude/settings.json  peers/claude/protocol.md
    peers/<role>/watch.pid  peers/<role>/rung
    peers/agy/profile.json  peers/agy/conversation_id  peers/agy/last_input  peers/agy/watchdog  peers/<peer>/hooks.log
    .agents/hooks.json  .agents/rules/AGENTS.md
  repos/<sha256(realpath(toplevel))[:16]>/current   # session dir name
  repos/<hash>/path                                 # repo toplevel, for status
  agy-check.json                                    # self-check result keyed by `agy --version`
```

`session.json`:

```json
{"name":"fix-csv-bom","dir":"apix--fix-csv-bom","repo":"/Users/.../apix",
 "ticket":"APIX-123","task":"text or null","test_cmds":["dip rspec"],

 "created":"2026-11-11T10:00:00Z","ended":null,"replaced_by":null,

```

### Naming

- `tandem init` → branch name after the last `/`; on `main`, `master` or detached HEAD →
  `<repo>-MMDD-HHMM`. `tandem init <name>` → as given. `--ticket KEY` without a name → the key.
- Sanitize: lowercase, runs of non-`[a-z0-9]` → `-`, trim `-`, cap 48 chars. Dir is
  `<sanitized repo>--<name>`; an existing dir (active or ended) → `-2`, `-3`, ….
- Test prefixes: `go.mod` → `go test`; `dip.yml` → `dip rspec`; `Gemfile` without `dip.yml` →
  `bundle exec rspec`; `--test-cmd` (repeatable) replaces detection.

### Resolution (first match wins)

1. `--session <name>`: a full dir name, or a short name matched within the current repo, or a
   globally unique short name.
2. `TANDEM_SESSION` (full dir name, set by launchers).
3. Repo pointer for `git rev-parse --show-toplevel`, if it points at an active session.
4. The only active session on the machine, only when outside any git repo (Task 4: inside a repo
   or worktree without its own session this would attach a launcher to another tree's session).
5. Error listing active sessions (and a stale pointer, if one was found in step 3).

### Envelope and log

```json
{"id":"0007","ts":"…","from":"driver","to":"navigator","type":"review_request",
 "reply_to":"0005","expects_reply":true,"refs":{"commit":"abc123","files":["plan.md"]},
 "body":"markdown…"}
```

- Types: `plan`, `review_request`, `review`, `question`, `answer`, `decision`, `escalate`, `done`.
  `expects_reply` defaults to true for `plan`, `review_request`, `question`, `escalate`;
  `--expects-reply` / `--no-reply` override.
- Maildir filename: `<id>.json`; oldest = lowest id.
- `log.jsonl` lines carry `kind`: `message` (full envelope), `console` (human typed in a harness:
  `{"kind":"console","ts","from":"human","to":<role>,"peer":<peer>,"body"}`), `event` (init, role
  claimed, watcher started/exited, done).

### CLI surface and exit codes

| Command | Notes |
|---|---|
| `tandem init [name] [--ticket K] [--task T \| --task-file F] [--test-cmd C]… [--replace]` | prints the session dir |
| `tandem send [--as R] --to R [--type T] [--reply-to ID] [--commit X] [--file F]… [--expects-reply \| --no-reply] [body]` | body from arg or stdin |
| `tandem recv [--as R] [--peek] [--wait] [--timeout S] [--json]` | human-readable by default |
| `tandem watch [--as R] (--once [--deadline S] \| --detach)` | |
| `tandem log [--json] [-f]` | |
| `tandem status` | sessions, pending per inbox, last message per role, watcher liveness, stale pointers |
| `tandem done` | |
| `tandem claude [--role R] [-- extra claude args]` / `tandem agy [--role R] [--profile auto\|fallback] [-- extra]` | `exec` |
| `tandem human` | REPL |
| `tandem hook <event>` | internal; stdin JSON → stdout JSON |

Exit codes: `0` ok, `1` error, `2` mail (only `watch --once`, the asyncRewake wake), `3` no mail
or timeout (`recv`).

Doorbell text (fixed, content-free):
`tandem doorbell: new mail for <role>. Run \`tandem recv\`.`

### Generated configs (shapes)

Claude `peers/claude/settings.json`:

```json
{"hooks":{
   "Stop":[{"hooks":[{"type":"command","asyncRewake":true,"timeout":14400,
     "command":"'<shim>' --session <dir> watch --as <role> --once --deadline 14340"}]}],
   "UserPromptSubmit":[{"hooks":[{"type":"command",
     "command":"'<shim>' --session <dir> hook claude-prompt"}]}]},
 "permissions":{"allow":["Bash(tandem *)"],
                "deny":["Edit","Write","NotebookEdit"]}} // deny: navigator only
```

`exec claude --add-dir <session dir> --settings <file> --append-system-prompt "$(cat peers/claude/protocol.md)" [extra] -- <initial prompt>`
(Task 12: `--add-dir` so session files need no prompt; `--` so a variadic extra flag can't eat the prompt).
The initial prompt (a fixed `tandem:`-prefixed line) gives the session a first turn so the Stop
hook arms; the prompt hook skips lines with that prefix so it isn't logged as human input.

Rule syntax (Task 1, Claude docs): `Bash(tandem *)` matches `tandem` and `tandem …`, not
`tandemx`; agents must call plain `tandem`, since rules match command text.

agy `.agents/hooks.json` (agy's own format: top-level keys are hook **names**, each holding event
arrays; event names at the top level load nothing, verified in Task 1 with `-p=/hooks`):

```json
{"tandem":{
  "PreToolUse":[{"matcher":"run_command","hooks":[{"command":"'<shim>' --session <dir> hook agy-pretool"}]}],
  "SessionStart":[{"command":"'<shim>' --session <dir> hook agy-session-start"}],
  "PreInvocation":[{"command":"'<shim>' --session <dir> hook agy-preinvocation"}],
  "Stop":[{"command":"'<shim>' --session <dir> hook agy-stop"}]}}
```

agy profiles (`peers/agy/profile.json`):

| Profile | Contents |
|---|---|
| navigator (default) | `proceed-in-sandbox`, `enableTerminalSandbox: true`, allow `unsandboxed(<test prefix>)`… + `unsandboxed(tandem)`, deny `write_file(*)` + the user's global deny |
| navigator fallback | `request-review`, no sandbox, allow `command(tandem)`, read-only git (`command(git status)`, `command(git diff)`, `command(git log)`, `command(git show)`), exact test commands as `command(...)`, deny `write_file(*)` + the user's global deny |
| driver | `request-review`, no sandbox, allow `command(tandem)`, `command(git)`, deny = the user's global deny (often `[]`); launched with `--mode auto` |

Every profile writes both `permissions.allow` and `permissions.deny` (an empty list if needed):
`--settings` replaces each key separately, so an omitted `deny` keeps the user's global one (Task 1),
and a written one, even `[]`, replaces it (Task 14). So `deny` is tandem's own rules followed by
the user's global ones, read (never written) from `~/.gemini/antigravity-cli/settings.json`
`permissions.deny` and deduplicated (Task 15); a missing or unreadable file adds nothing. The
user's global `allow` is not carried over: the profile's allowlist is the whole allowlist.

`exec agy --settings peers/agy/profile.json --add-dir <session dir> [--mode auto] --prompt-interactive=<initial prompt> [extra]`
(`-i`/`--prompt-interactive` runs an initial prompt and stays interactive; no positional prompt).
The initial prompt is a fixed `tandem:` line (skipped by `agy-preinvocation`) that gives agy its
first turn, so `SessionStart` fires and tells it to start its watcher.

Self-check (navigator, `--profile auto`): `agy --version`, then `agy --settings <navigator profile
in a temp dir> -p=/config --output-format json`; it passes when `command.data.config` shows the
profile's `toolPermission`, `enableTerminalSandbox` and every allow/deny rule, and neither stream
carries agy's "unsandboxed is unsupported" notice. Fail → fallback profile + one-line warning. Pass
on a version outside `VERIFIED_AGY_VERSIONS` (1.5.4, 1.5.5) → navigator profile kept + one-line
warning suggesting `--profile fallback`. Result cached in `$TANDEM_HOME/agy-check.json` by version
(timeouts are not cached).

### agy hook behaviour

| Hook | Does |
|---|---|
| `agy-pretool` | in order: (1) `CommandLine` starts with a bypass prefix (test command or `tandem`, whole words) and has no separator, redirect or expansion outside quotes (single-quoted text is literal) → `{"decision":"allow","overwrite":{"BypassSandbox":true}}`; (2) agy isn't the driver and the command looks like a write (writer command, `sed -i`/`perl -i`, output redirect other than `/dev/null`/fd dup, tree/ref-changing `git` subcommand, `find -delete`), checked in every segment incl. `$(…)` and subshells → `{"decision":"force_ask","reason":…}` (best effort); (3) otherwise `{"decision":"ask"}`. Never emits `{}` (that denies). Analysis in `tandem/cmdline.py`. |
| `agy-session-start` | writes `conversationId`; injects a system message with role, session and "run `tandem watch --detach`" if the watcher isn't alive, plus "N messages pending, run `tandem recv`" if any (and marks that mail rung, so the watcher doesn't ring it again) |
| `agy-preinvocation` | writes `conversationId`; logs `lastUserInput` as `console` unless it starts with `tandem doorbell` or `tandem:`, or equals `peers/agy/last_input` (dedupe) |
| `agy-stop` | writes `conversationId`; only when `terminationReason == NO_TOOL_CALL` and `fullyIdle`: watcher dead → `continue` "run `tandem watch --detach`"; unrung mail → `continue` "run `tandem recv`" and mark rung; both reasons go in one `continue`; the watcher nudge is repeated at most once per 60 s (`peers/agy/watchdog`), so a watcher that can't start doesn't loop agy; otherwise the no-op output `{}` (Task 1: only `"decision":"continue"` blocks a stop) |
